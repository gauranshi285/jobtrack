# ?? JobTrack v3 - Job Application Tracker

Intermediate Java Project | Spring Boot + H2 + REST API + Deployable

## Features
- Add / View / Delete Job Applications
- REST API - /api/jobs
- H2 File Database (persistent)
- Deployable JAR

## Tech Stack
- Java 21, Spring Boot 3.2, Spring Data JPA
- H2 Database, Maven
- HTML + JS Frontend

## How to Run
mvn clean package -DskipTests
java -jar target/simple-java-project-1.0.0.jar

Open: http://localhost:8080

## API
- GET /api/jobs - List all jobs
- POST /api/jobs - Add job
